## Контрольные вопросы

**Что такое URL?** Унифицированный адрес ресурса: протокол, адрес узла, путь (например, `file:///C:/work/page.html` или `http://localhost:8080/index.html`). В программе файл превращается в URL методом `file.toURI().toURL()`.

**Как программно получить список всех файлов в папке?** Метод `listFiles()` объекта `File`, созданного для папки: `new File("source_html").listFiles()` – массив файлов.

**Как программно запустить браузер и открыть html-файл?** `Desktop.getDesktop().browse(uri)` – открыть адрес в браузере по умолчанию; `uri` получают из файла `file.getAbsoluteFile().toURI()`.

**Объясните использование потоковых классов в приложении.** `URLConnection.getInputStream()` даёт поток байтов, `InputStreamReader` преобразует байты в символы в кодировке UTF-8, `BufferedReader` читает построчно методом `readLine()` через буфер. Блок `try-with-resources` закрывает потоки автоматически.

## Что могут спросить дополнительно (из чата и по теме)

- **Зачем нужен буфер?** Три назначения: выравнивание скоростей диска и памяти, асинхронный ввод-вывод, кэширование (подробно в [ТЕОРИЯ_ИЗ_ЧАТА_АИРП.md](ТЕОРИЯ_ИЗ_ЧАТА_АИРП.md)).
- **Чем отличаются массив, `ArrayList` и `List`?** Массив – фиксированный размер; `ArrayList` – растущий список на основе массива; `List` – интерфейс списка (термин из Пролога: упорядоченная последовательность элементов).
- **Что такое `ArrayList<String>` в коде?** Список строк, в который читаются строки файла.
- **Почему `split("\\|")`?** `|` в регулярных выражениях – специальный символ, поэтому его экранируют `\|`, а в строке Java обратную черту записывают двойной.
- **Что будет при равенстве совпадений?** Выбирается лекарство, которое встретилось в файле первым (сравнение строгое `>`).
- **Что, если слово не найдено?** Все счётчики 0, программа пишет «Лекарство не найдено», браузер не открывается.
