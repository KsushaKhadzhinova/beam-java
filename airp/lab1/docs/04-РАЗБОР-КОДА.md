## 1. Пакет, импорты, класс и поля

## 3. actionPerformed: что происходит при нажатии кнопок

```java
public void actionPerformed(ActionEvent ae) {
    if (ae.getSource() == exitButton) {
        System.exit(0);
    } else if (ae.getSource() == searchButton) {
        // Ключевые слова (симптомы) разделяются запятыми
        String[] keywords = textArea.getText().split(",");
        textArea.setText("");

        // Список лекарств читается из текстового файла
        File medicinesFile = new File("medicines.txt");
        ArrayList<String> medicines = readLines(medicinesFile);

        String bestName = null;
        int bestCount = 0;
        for (String line : medicines) {
            // Формат строки: Название | симптом1, симптом2, ...
            String[] parts = line.split("\\|");
            if (parts.length < 2) {
                continue;
            }
            String name = parts[0].trim();
            int coincidenceCount = testSymptoms(parts[1], keywords);
            textArea.append("\n" + name + "  :" + coincidenceCount);
            if (coincidenceCount > bestCount) {
                bestCount = coincidenceCount;
                bestName = name;
            }
        }

        if (bestName == null) {
            textArea.append("\nЛекарство не найдено");
        } else {
            textArea.append("\n\nЛекарство: " + bestName);
            openInBrowser(new File("source_html", bestName + ".html"));
        }
    }
}
```

| Строка | Разбор |
|---|---|
| `@Override public void actionPerformed(ActionEvent ae)` | метод, который Java вызывает при нажатии любой кнопки, на которую мы подписались; `ae` – описание события |
| `if (ae.getSource() == exitButton) { System.exit(0); }` | источник события – кнопка `Exit`? Тогда выйти |
| `else if (ae.getSource() == searchButton) {` | иначе, если это `Search` |
| `String[] keywords = textArea.getText().split(",");` | взять текст из поля и **разрезать по запятым**: получится массив строк |
| `textArea.setText("");` | очистить поле для вывода результата |
| `File medicinesFile = new File("medicines.txt");` | объект «файл» (путь относительный, от места запуска) |
| `ArrayList<String> medicines = readLines(medicinesFile);` | прочитать все строки файла нашим методом `readLines` (ниже); `ArrayList<String>` – список строк |
| `String bestName = null; int bestCount = 0;` | «лучшее лекарство» и лучшее число совпадений; пока ничего не найдено |
| `for (String line : medicines)` | **цикл по списку**: `line` по очереди равна каждой строке |
| `String[] parts = line.split("\\|");` | разрезать по символу `\|` (в регулярном выражении `|` нужно экранировать обратной чертой, а в строке Java обратную черту удваивают) |
| `if (parts.length < 2) { continue; }` | пропустить некорректные строки |
| `String name = parts[0].trim();` | название лекарства без пробелов по краям; `parts[0]` – часть до `\|` |
| `int coincidenceCount = testSymptoms(parts[1], keywords);` | посчитать совпадения в части после `\|` |
| `textArea.append("\n" + name + "  :" + coincidenceCount);` | дописать строку «название  :число» в поле |
| `if (coincidenceCount > bestCount) { ... }` | если совпадений больше, чем у лучшего, запомнить это лекарство |
| `if (bestName == null) { textArea.append("\nЛекарство не найдено"); }` | никто не подошёл |
| `else { ... openInBrowser(new File("source_html", bestName + ".html")); }` | вывести «Лекарство: …» и открыть файл `source_html/<название>.html` |

## 4. readLines: чтение файла через URL и потоки

```java
// Чтение строк файла через URL и потоковые классы
private ArrayList<String> readLines(File file) {
    ArrayList<String> lines = new ArrayList<>();
    try {
        URL url = file.toURI().toURL();
        URLConnection connection = url.openConnection();
        try (BufferedReader reader = new BufferedReader(
                new InputStreamReader(connection.getInputStream(), "UTF-8"))) {
            String line;
            while ((line = reader.readLine()) != null) {
                if (!line.trim().isEmpty() && !line.startsWith("#")) {
                    lines.add(line);
                }
            }
        }
    } catch (IOException e) {
        System.out.println("Error: " + e.getMessage());
    }
    return lines;
}
```

| Строка | Разбор |
|---|---|
| `private ArrayList<String> readLines(File file)` | `private` – метод только для этого класса; возвращает список строк |
| `ArrayList<String> lines = new ArrayList<>();` | пустой список (`<>` – тип выводится сам) |
| `URL url = file.toURI().toURL();` | файл → адрес `file:///...` |
| `URLConnection connection = url.openConnection();` | соединение с ресурсом |
| `try (BufferedReader reader = new BufferedReader(new InputStreamReader(connection.getInputStream(), "UTF-8")))` | цепочка потоков: **байты → символы (UTF-8) → буфер строк**; `try (...)` – закрыть автоматически |
| `while ((line = reader.readLine()) != null)` | читать строки, пока не `null` (конец файла); присваивание внутри условия |
| `if (!line.trim().isEmpty() && !line.startsWith("#"))` | пропустить пустые строки и комментарии (строки с `#`) |
| `lines.add(line);` | добавить в список |
| `catch (IOException e) { System.out.println("Error: " + e.getMessage()); }` | если ошибка чтения, вывести сообщение в консоль |
| `return lines;` | вернуть результат |

## 5. testSymptoms: подсчёт совпадений

```java
// Число ключевых слов, найденных среди симптомов лекарства
private int testSymptoms(String symptoms, String[] keywords) {
    int results = 0;
    String content = symptoms.toLowerCase();
    for (String keyword : keywords) {
        if (!keyword.trim().isEmpty() && content.contains(keyword.trim().toLowerCase())) {
            results++;
        }
    }
    return results;
}
```

| Строка | Разбор |
|---|---|
| `private int testSymptoms(String symptoms, String[] keywords)` | принимает строку симптомов и массив ключевых слов; возвращает число совпадений |
| `String content = symptoms.toLowerCase();` | привести к нижнему регистру, чтобы «Головная» и «головная» совпадали |
| `for (String keyword : keywords)` | цикл по ключевым словам |
| `!keyword.trim().isEmpty()` | пропустить пустые слова |
| `content.contains(keyword.trim().toLowerCase())` | **содержит ли строка симптомов это слово** (подстрока) |
| `results++;` | увеличить счётчик на 1 |

## 6. openInBrowser и main

```java
    // Открытие html-документа в браузере
    private void openInBrowser(File file) {
        try {
            Desktop.getDesktop().browse(file.getAbsoluteFile().toURI());
        } catch (IOException e) {
            System.out.println("Error: " + e.getMessage());
        }
    }

    public static void main(String[] args) {
        new Web_res_lab();
    }
}
```

| Строка | Разбор |
|---|---|
| `Desktop.getDesktop().browse(file.getAbsoluteFile().toURI());` | `getDesktop()` – доступ к «рабочему столу» ОС; `browse` – открыть адрес в браузере по умолчанию; `getAbsoluteFile().toURI()` – полный путь файла в виде URI |
| `public static void main(String[] args)` | **точка входа Java-программы**: JVM запускает именно этот метод |
| `new Web_res_lab();` | создать окно (вызывается конструктор); после этого программа живёт, пока открыто окно |
