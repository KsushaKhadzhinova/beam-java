# АИРП-1. Теория кратко

- **URL** – адрес ресурса (`протокол://узел/путь`); в Java `URL` + `URLConnection` читают и локальные файлы, и сайты.
- **Цепочка потоков:** `InputStream` (байты) → `InputStreamReader(UTF-8)` (символы) → `BufferedReader` (строки, `readLine()`).
- **Буфер:** выравнивание скоростей, асинхронный ввод-вывод, кэширование (3 назначения).
- **Файлы папки:** `new File("папка").listFiles()`.
- **Открыть браузер:** `Desktop.getDesktop().browse(uri)`.
- **Окно AWT:** `Frame`, `Button`, `TextArea`; кнопки обрабатывает `ActionListener.actionPerformed`; `System.exit(0)` закрывает.
- **Алгоритм:** разбить запрос по запятым → прочитать `medicines.txt` → для каждой строки посчитать совпадения симптомов → вывести → открыть html лучшего.
- **Вариант 2:** поиск названия лекарства по 1–3 симптомам из текстового файла.
- Данные составлены для лабы; нужно согласовать с преподавателем.
