## 1. Импорты и комментарий

```java
import java.awt.*;
import java.awt.event.*;
import java.io.*;
import java.net.*;
import java.util.Enumeration;

// Вариант 2: два клиента, каждый в своём потоке.
// Клиент 1 добавляет и снимает деньги со счёта, клиент 2 только снимает.
//
// Запуск:
//   java -jar serv.jar             - сервер и клиенты на одном компьютере (адрес 127.0.0.1)
//   java -jar serv.jar 192.168.0.5 - только клиенты, сервер работает на компьютере с указанным адресом
```

| Строка | Разбор |
|---|---|
| `import java.awt.*;` | классы окон AWT |
| `import java.awt.event.*;` | события (`ActionListener`, `WindowAdapter`) |
| `import java.io.*;` | потоки (`PrintStream`, `BufferedReader`, `DataInputStream`) |
| `import java.net.*;` | сеть (`Socket`, `ServerSocket`, `NetworkInterface`, `InetAddress`) |
| `import java.util.Enumeration;` | перечисление, которое возвращают методы `NetworkInterface` |
| комментарий про запуск | `java -jar serv.jar` – режим «сервер», `java -jar serv.jar <IP>` – режим «клиент» |

Файл не содержит строки `package`: классы лежат в **пакете по умолчанию**, поэтому запускаются просто `serv`.

## 2. Серверный поток Account

```java
// Серверный поток: хранит счёт и обрабатывает запросы клиентов
class Account extends Thread {
    ServerSocket server;
    String amountstring;
    static int amount = 200;
    serv window; // окно, в журнал которого сервер записывает запросы

    public Account(serv window) {
        this.window = window;
    }

    public void run() {
        try {
            server = new ServerSocket(3001); // Номер сокета
        } catch (Exception e) {
            System.out.println("Ошибка соединения+" + e);
        }
        while (true) {
            Socket s = null;
            try {
                s = server.accept(); // ожидание соединения с клиентом
            } catch (Exception e) {
                System.out.println("Ошибка" + e);
            }
            try {
                // Чтение запроса клиента (ADD или WITHDRAW)
                BufferedReader in = new BufferedReader(new InputStreamReader(s.getInputStream()));
                String request = in.readLine();

                PrintStream ps = new PrintStream(s.getOutputStream()); // PrintStream предназначен для текстового вывода
                int amountcur = ((int) (Math.random() * 1000));
                if (request.equals("ADD"))
                    amount += amountcur;
                else
                    amount -= amountcur;
                amountstring = Integer.toString(amount);
                ps.println("Account:" + amountstring); // передача строки клиенту
                ps.flush();
                // Запись в журнал сервера: откуда пришёл запрос и каким стал счёт
                window.log.append("[сервер] " + request + " от " + s.getInetAddress().getHostAddress() + ", счёт: " + amountstring + "\n");
                window.accountField.setText(amountstring);
                s.close(); // Сокетное соединение закрывается
            } catch (Exception e) {
                System.out.println("Ошибка  " + e);
            }
        }
    }
}
```

| Строка | Разбор |
|---|---|
| `class Account extends Thread` | класс – **поток**: наследуется от `Thread`, значит имеет метод `run()` и запускается `start()` |
| `ServerSocket server;` | серверный сокет |
| `String amountstring;` | текст счёта для отправки |
| `static int amount = 200;` | **общий счёт**: `static` – один на весь класс (глобальная переменная); начальное значение 200 |
| `serv window;` | ссылка на окно, чтобы писать в его журнал |
| `public Account(serv window) { this.window = window; }` | **конструктор**: запоминает окно; `this.window` – поле класса, `window` – параметр |
| `public void run()` | то, что поток выполняет после `start()` |
| `server = new ServerSocket(3001);` | создать серверный сокет на порту 3001, начать слушать; в `try/catch`, потому что порт может быть занят |
| `while (true)` | бесконечный цикл: сервер обслуживает клиентов, пока работает программа |
| `Socket s = null;` | соединение с клиентом (пока нет) |
| `s = server.accept();` | **ждать клиента**; поток стоит здесь, пока не подключится клиент; возвращает сокет этого клиента |
| `BufferedReader in = new BufferedReader(new InputStreamReader(s.getInputStream()));` | читатель текста поверх входного потока сокета |
| `String request = in.readLine();` | **прочитать запрос клиента**: `ADD` или `WITHDRAW` |
| `PrintStream ps = new PrintStream(s.getOutputStream());` | писатель текста поверх выходного потока сокета |
| `int amountcur = ((int) (Math.random() * 1000));` | случайное целое 0–999: `Math.random()` – число от 0 до 1, умножаем на 1000, `(int)` – отбрасываем дробную часть |
| `if (request.equals("ADD")) amount += amountcur; else amount -= amountcur;` | прибавить или вычесть; строки сравнивают `equals`, не `==` |
| `amountstring = Integer.toString(amount);` | число → текст |
| `ps.println("Account:" + amountstring);` | **ответ клиенту**: `Account:418` |
| `ps.flush();` | принудительно отправить (буфер → сеть) |
| `window.log.append("[сервер] " + request + " от " + s.getInetAddress().getHostAddress() + ", счёт: " + amountstring + "\n");` | запись в журнал окна: какой запрос и **откуда** (IP клиента) пришёл |
| `window.accountField.setText(amountstring);` | показать счёт на сервере |
| `s.close();` | закрыть соединение; цикл вернётся к `accept()` |
| `catch (Exception e) { System.out.println("Ошибка " + e); }` | при ошибке вывести сообщение в консоль и продолжить |

## 3. Клиентский поток clientThread

```java
// Клиентский поток: отправляет запрос серверу и читает ответ
class clientThread extends Thread {
    DataInputStream dis = null;
    Socket s = null;
    String name;
    String request;
    String host;
    serv window;

    public clientThread(String name, String request, serv window, String host) {
        this.name = name;
        this.request = request;
        this.window = window;
        this.host = host;
        try {
            s = new Socket(host, 3001);
            dis = new DataInputStream(s.getInputStream());
        } catch (Exception e) {
            System.out.println("Ошибка:  " + e);
        }
    }

    public void run() {
        if (s == null) { // соединение не установлено
            window.log.append(name + ": нет связи с сервером " + host + "\n");
            return;
        }
        try {
            // Отправка запроса серверу
            PrintStream ps = new PrintStream(s.getOutputStream());
            ps.println(request);
            ps.flush();

            String msg = dis.readLine(); // Клиент читает строку из сокета
            if (msg != null) {
                System.out.println(name + ": " + msg);
                window.showMessage(name + ": " + msg);
            }
            s.close();
        } catch (Exception e) {
            System.out.println("ERRORR+" + e);
        }
    }
}
```

| Строка | Разбор |
|---|---|
| `class clientThread extends Thread` | клиент – тоже **поток** |
| `DataInputStream dis = null; Socket s = null;` | поток чтения и сокет; пока `null` |
| `String name; String request; String host; serv window;` | имя клиента («Клиент 1»), команда, адрес сервера, окно |
| `public clientThread(String name, String request, serv window, String host)` | конструктор принимает всё нужное и **сразу подключается** |
| `s = new Socket(host, 3001);` | **подключиться к серверу**: адрес `host`, порт 3001. Если сервер недоступен, будет исключение |
| `dis = new DataInputStream(s.getInputStream());` | читатель ответа |
| `catch (Exception e)` | если подключиться не удалось, `s` остаётся `null` |
| `if (s == null) { window.log.append(name + ": нет связи с сервером " + host + "\n"); return; }` | сообщение об ошибке в журнал клиента, `return` – выйти из `run()` |
| `PrintStream ps = new PrintStream(s.getOutputStream()); ps.println(request); ps.flush();` | **отправить запрос серверу** (направление «клиент → сервер») |
| `String msg = dis.readLine();` | **прочитать ответ** (строка вида `Account:418`) |
| `window.showMessage(name + ": " + msg);` | показать в окне |
| `s.close();` | закрыть соединение |

## 4. Окно serv: поля и конструкторы

```java
// Окно приложения
public class serv extends Frame implements ActionListener {
    Button client1Add = new Button("Клиент 1: добавить");
    Button client1Withdraw = new Button("Клиент 1: снять");
    Button client2Withdraw = new Button("Клиент 2: снять");
    TextField accountField = new TextField("200", 10);
    TextArea log = new TextArea(8, 40);
    String host; // адрес компьютера, на котором работает сервер

    public serv() {
        this("127.0.0.1");
    }

    public serv(String host) {
        super("Счёт");
        this.host = host;
        setLayout(new FlowLayout());
        add(client1Add);
        add(client1Withdraw);
        add(client2Withdraw);
        add(new Label("Счёт:"));
        add(accountField);
        add(log);

        client1Add.addActionListener(this);
        client1Withdraw.addActionListener(this);
        client2Withdraw.addActionListener(this);

        addWindowListener(new WindowAdapter() {
            public void windowClosing(WindowEvent we) {
                System.exit(0); // Закрыть приложение
            }
        });
    }
```

| Строка | Разбор |
|---|---|
| `public class serv extends Frame implements ActionListener` | главный класс: окно + обработчик кнопок |
| `Button client1Add = new Button("Клиент 1: добавить");` и две другие | три кнопки |
| `TextField accountField = new TextField("200", 10);` | однострочное поле счёта (начально «200», ширина 10 знаков) |
| `TextArea log = new TextArea(8, 40);` | журнал: 8 строк по 40 знаков |
| `String host;` | **адрес сервера**, к которому подключаются клиентские потоки |
| `public serv() { this("127.0.0.1"); }` | конструктор без параметров вызывает другой с адресом `127.0.0.1` (**свой компьютер**) |
| `public serv(String host)` | основной конструктор; `super("Счёт")` – заголовок окна; `setLayout(new FlowLayout())` – элементы идут подряд слева направо с переносом |
| `add(...)` | добавить элементы в окно |
| `client1Add.addActionListener(this);` | подписать окно на нажатия кнопок |
| `addWindowListener(new WindowAdapter() { windowClosing ... System.exit(0); })` | закрытие окна завершает программу |

## 5. Обработка нажатий и вывод

```java
// Запуск клиента по нажатию кнопки
public void actionPerformed(ActionEvent ae) {
    if (ae.getSource() == client1Add)
        new clientThread("Клиент 1", "ADD", this, host).start();
    else if (ae.getSource() == client1Withdraw)
        new clientThread("Клиент 1", "WITHDRAW", this, host).start();
    else if (ae.getSource() == client2Withdraw)
        new clientThread("Клиент 2", "WITHDRAW", this, host).start();
}

// Отображение состояния счёта
public void showMessage(String message) {
    accountField.setText(message.substring(message.indexOf(':', message.indexOf(':') + 1) + 1));
    log.append(message + "\n");
}
```

| Строка | Разбор |
|---|---|
| `public void actionPerformed(ActionEvent ae)` | вызывается при нажатии любой кнопки |
| `if (ae.getSource() == client1Add) new clientThread("Клиент 1", "ADD", this, host).start();` | если нажата первая кнопка – создать клиентский поток (имя, команда, окно `this`, адрес сервера) и **запустить** (`start()`) |
| `client1Withdraw` → `"WITHDRAW"` для «Клиент 1» | клиент 1 снимает |
| `client2Withdraw` → `"WITHDRAW"` для «Клиент 2» | клиент 2 **только снимает** (вариант 2) |
| `showMessage(String message)` | показать ответ; `message.indexOf(':', message.indexOf(':') + 1) + 1` – найти **второе двоеточие** в строке «Клиент 1: Account:418» (после слова Account); `substring(...)` – взять всё после него: «418»; `accountField.setText(...)` – показать число; `log.append(...)` – дописать строку в журнал |

## 6. localAddresses: IP-адреса этого компьютера

```java
// IP-адреса этого компьютера в локальной сети (для ввода на других компьютерах)
static String localAddresses() {
    String result = "";
    try {
        Enumeration<NetworkInterface> interfaces = NetworkInterface.getNetworkInterfaces();
        while (interfaces.hasMoreElements()) {
            NetworkInterface ni = interfaces.nextElement();
            if (!ni.isUp() || ni.isLoopback())
                continue;
            Enumeration<InetAddress> addresses = ni.getInetAddresses();
            while (addresses.hasMoreElements()) {
                InetAddress address = addresses.nextElement();
                if (address instanceof Inet4Address)
                    result += address.getHostAddress() + " ";
            }
        }
    } catch (Exception e) {
        System.out.println("Ошибка " + e);
    }
    return result.trim();
}
```

| Строка | Разбор |
|---|---|
| `NetworkInterface.getNetworkInterfaces()` | список сетевых адаптеров компьютера (Wi-Fi, виртуальные и др.) |
| `ni.isUp()` / `ni.isLoopback()` | адаптер включён / это «петля» 127.0.0.1 (её пропускаем: `continue`) |
| `ni.getInetAddresses()` | адреса адаптера |
| `address instanceof Inet4Address` | проверка типа: берём только адреса версии IPv4 (вида 192.168.0.5) |
| `result += address.getHostAddress() + " ";` | дописать адрес в строку результата |
| `return result.trim();` | вернуть без лишнего пробела в конце |

Эти адреса показываются в заголовке окна сервера, чтобы вводить их на других компьютерах.

## 7. main: два режима

```java
    public static void main(String args[]) {
        if (args.length == 0) { // сервер и клиенты на одном компьютере
            serv f = new serv();
            f.setTitle("Счёт (сервер, IP: " + localAddresses() + ")");
            f.setSize(400, 400);
            f.setVisible(true);
            new Account(f).start();
        } else { // только клиенты, сервер на другом компьютере
            serv f = new serv(args[0]);
            f.setTitle("Счёт (клиент, сервер: " + args[0] + ")");
            f.setSize(400, 400);
            f.setVisible(true);
        }
    }
}
```

| Строка | Разбор |
|---|---|
| `public static void main(String args[])` | **точка входа**; `args` – аргументы командной строки |
| `if (args.length == 0)` | **аргументов нет** – режим «сервер и клиенты на одном компьютере» |
| `serv f = new serv(); f.setTitle("Счёт (сервер, IP: " + localAddresses() + ")");` | создать окно, в заголовок поместить IP-адреса |
| `f.setSize(400, 400); f.setVisible(true);` | размер и показ |
| `new Account(f).start();` | **запустить серверный поток**, передав ему окно |
| `else` – аргумент есть | режим «**только клиенты**»: `args[0]` – IP-адрес сервера |
| `new serv(args[0])` | окно, клиентские потоки которого подключаются к этому IP; серверный поток **не запускается** |
