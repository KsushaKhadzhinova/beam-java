## Контрольные вопросы

**1. Назначение TCP, UDP; различие.** TCP – с установлением соединения, гарантирует доставку и порядок, повторно передаёт потерянные пакеты. UDP – без соединения, без гарантий, быстрее. В лабораторной используется TCP (`ServerSocket`, `Socket`).

**2. С помощью каких объектов и методов данные отсылаются по сети?** Через выходной поток сокета: `PrintStream ps = new PrintStream(s.getOutputStream())`, методы `println()` (записать строку) и `flush()` (отправить буфер). Читают через `getInputStream()` (`DataInputStream.readLine()`, `BufferedReader.readLine()`).

**3. Как реализовать пересылку данных в обратном направлении (от клиента к серверу)?** Клиент пишет в `PrintStream` над `s.getOutputStream()`, сервер читает `BufferedReader` над `s.getInputStream()` методом `readLine()`. У нас так передаются запросы `ADD` и `WITHDRAW`.

**4. Как определить сетевой адрес вашего компьютера?** Windows: `ipconfig`; Mac/Linux: `ifconfig`/`ip addr`/`hostname -I`; в Java: `InetAddress.getLocalHost().getHostAddress()` или перебор `NetworkInterface` (как в `localAddresses()`). 127.0.0.1 – «этот же компьютер».

## Дополнительные вопросы

- **Что такое сокет?** Программная точка соединения: IP + порт.
- **Что такое порт, какой у нас?** Номер приложения на компьютере; 3001. Если занят – сервер не запустится.
- **Почему `accept()` в цикле?** Чтобы обслуживать много клиентов по очереди.
- **Почему клиент и сервер – потоки?** Чтобы окно не «зависало» и сервер постоянно слушал.
- **Почему `flush()`?** Данные накапливаются в буфере; `flush()` отправляет их сразу.
- **Что делает `readLine()`?** Читает строку до конца строки; `null`, если поток закрыт.
- **Что будет, если сервер не запущен?** `new Socket(...)` выбросит `ConnectException` (в нашей программе перехватывается, в журнал пишется «нет связи с сервером»).
- **Зачем закрывать сокет?** Освободить системные ресурсы.
- **Что с отрицательным счётом?** Задание не запрещает: случайная сумма снимается без проверки остатка.
- **Потоки или процессы?** У нас потоки одного процесса; общий счёт – статическая переменная. Через процессы можно: сервер и клиенты отдельными программами (так в режиме трёх компьютеров), обмен только через сокет.
