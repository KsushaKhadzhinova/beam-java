# АИРП-2. Теория кратко

- **Сокет** = IP-адрес + порт; `ServerSocket(3001)` слушает, `accept()` ждёт клиента (блокирует поток); `new Socket("адрес", 3001)` – клиент.
- **IP** – адрес компьютера (`127.0.0.1` – свой), **порт** – адрес приложения внутри компьютера.
- **TCP** – с соединением, гарантия доставки и порядка, повторная передача; **UDP** – без соединения и гарантий. Оба поверх **IP**.
- **Отправка:** `PrintStream ps = new PrintStream(s.getOutputStream()); ps.println(...); ps.flush();`
- **Чтение:** `DataInputStream.readLine()` / `BufferedReader.readLine()`.
- **Клиент → сервер:** клиент пишет в `getOutputStream()`, сервер читает из `getInputStream()` (в лабе запросы `ADD`/`WITHDRAW`).
- **Потоки:** `extends Thread`, `run()`, `start()`; сервер и клиенты – потоки; счёт – `static int amount` (общая переменная).
- **Потоки vs процессы:** потоки делят память (глобальная переменная), процессы – только через сокеты.
- **Вариант 2:** клиент 1 добавляет и снимает, клиент 2 только снимает.
- **Три компьютера:** сервер `java -jar serv.jar`, клиенты `java -jar serv.jar <IP>`; открыть порт 3001.
- **Адрес компьютера:** `ipconfig` / `ifconfig` / `NetworkInterface`.
