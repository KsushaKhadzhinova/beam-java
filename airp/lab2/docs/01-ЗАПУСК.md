# АИРП, лабораторная работа 2. Как запустить

Тема: **Работа на основе сокетных соединений**. Вариант 2: два клиента через потоки; клиент 1 добавляет и снимает деньги, клиент 2 только снимает. Код в папке `airp/lab2`.

![Три компьютера](img/three_machines.png)

## Что в папке

| Файл | Для чего |
|---|---|
| `serv.jar` | **готовая программа** (Java 11+), запускается без компиляции |
| `src/serv.java` | исходный код |
| `1-start-server.bat` / `1-start-server.sh` | запустить **сервер + окно** (Windows / Mac, Linux) |
| `2-start-client.bat` / `2-start-client.sh` | запустить **клиентское окно** и подключиться к серверу по IP |
| `3-start-client-wsl.sh` | клиент в **Linux (WSL)** на том же ноутбуке, адрес Windows определяется сам |
| `show-ip.bat` / `show-ip.sh` | показать IP-адреса компьютера |
| `ADMIN-open-port-3001.bat` | открыть порт 3001 в брандмауэре Windows (**запускать от администратора**) |
| `ADMIN-close-port-3001.bat` | удалить это правило после защиты |

## Что установить (на каждом компьютере)

**Java 11 или новее** (JRE достаточно):

| Система | Как |
|---|---|
| **Windows** | скачать JDK 17 (например, Eclipse Temurin) и установить; проверка: `java -version` |
| **Mac** | `brew install --cask temurin` (если есть Homebrew) или установщик Temurin с adoptium.net; проверка: `java -version` |
| **Linux / WSL** | `sudo apt update && sudo apt install -y openjdk-17-jre`; проверка: `java -version` |

## Вариант А. Всё на одном компьютере (как в методичке)

Windows:

```bash
cd airp/lab2
java -jar serv.jar
```

или двойной щелчок по `1-start-server.bat`.

Откроется окно «Счёт (сервер, IP: ...)»: три кнопки, поле счёта, журнал. Внутри программы запускаются серверный поток (порт 3001) и клиентские потоки по нажатию кнопок. Адрес сервера – `127.0.0.1`.

Что нажимать:

| Кнопка | Что делает |
|---|---|
| Клиент 1: добавить | клиент 1 просит прибавить случайную сумму (0–999) |
| Клиент 1: снять | клиент 1 просит снять случайную сумму |
| Клиент 2: снять | клиент 2 (**только снимает**) просит снять случайную сумму |

В журнале видно и запись сервера «`[сервер] ADD от 127.0.0.1, счёт: 418`», и ответ клиента «`Клиент 1: Account:418`». Счёт может уйти в минус (методичка не запрещает).

## Вариант Б. Три компьютера (защита: «сервер и два клиента по Wi-Fi»)

Схема: **сервер – ноутбук с Windows**; **клиент 1 – Mac**; **клиент 2 – Linux (WSL)** на том же ноутбуке (или второй ноутбук).

### Шаг 1. Один раз: открыть порт на сервере

На ноутбуке с сервером: правой кнопкой по `ADMIN-open-port-3001.bat` → **Запуск от имени администратора**. Скрипт выполняет `netsh advfirewall firewall add rule ... localport=3001`: разрешает входящие подключения на порт 3001. После защиты запустите `ADMIN-close-port-3001.bat` (правило удаляется).

> Без этого шага клиенты **по Wi-Fi** (Mac) не подключатся: брандмауэр Windows блокирует входящие. Клиент из WSL на том же ноутбуке подключается и без правила (проверено).

### Шаг 2. Запустить сервер (Windows)

Двойной щелчок `1-start-server.bat`. Посмотрите IP в заголовке окна («Счёт (сервер, IP: **192.168.0.5** ...»). Если адресов несколько, нужен адрес Wi-Fi-адаптера: проверьте `show-ip.bat` (строка `IPv4 Address` у «Wireless LAN adapter Wi-Fi»). Все компьютеры должны быть в **одной Wi-Fi сети**.

### Шаг 3. Клиент на Mac

1. Скопировать на Mac папку `airp/lab2` (или только `serv.jar` и `2-start-client.sh`): через `git clone`, флешку, AirDrop.
2. Открыть Терминал и выполнить (подставьте IP сервера):

```bash
cd путь/к/lab2
sh 2-start-client.sh 192.168.0.5
```

или напрямую: `java -jar serv.jar 192.168.0.5`.

3. Откроется окно «Счёт (клиент, сервер: 192.168.0.5)». Нажимайте кнопки: на сервере в журнале появятся записи «`[сервер] ADD от <IP Mac>, счёт: ...`».

### Шаг 4. Клиент в Linux (WSL) на ноутбуке

В Windows: `Win` → запустить **Ubuntu** (или в PowerShell выполнить `wsl`). В Linux:

```bash
sudo apt update && sudo apt install -y openjdk-17-jre   # один раз
cd /mnt/e/путь/к/lab2                                   # диск Windows виден как /mnt/<буква>
sh 3-start-client-wsl.sh
```

Скрипт сам определяет адрес Windows (`ip route | awk '/default/ {print $3}'`) и запускает `java -jar serv.jar <адрес>`. Окно откроется на экране Windows (технология WSLg в Windows 11).

Если у вас второй физический ноутбук с Linux, используйте `2-start-client.sh <IP Windows>`.

### Шаг 5. Показ

1. Нажать «Клиент 1: добавить» на Mac → в журнале сервера запись с IP Mac.
2. Нажать «Клиент 2: снять» в Linux → запись с IP Linux. Счёт общий, виден на сервере.
3. Объяснить: сервер – поток `Account`, клиенты – потоки `clientThread`; общий счёт – `static int amount` в сервере.

## Если не подключается

| Проверка | Как |
|---|---|
| Порт доступен? | Windows: `Test-NetConnection 192.168.0.5 -Port 3001` (PowerShell); Mac/Linux: `nc -vz 192.168.0.5 3001` |
| Сервер запущен? | должно быть окно «Счёт (сервер…)»; в Windows: `netstat -ano \| findstr 3001` показывает `LISTENING` |
| Брандмауэр | выполнить `ADMIN-open-port-3001.bat` от администратора |
| Одна сеть? | IP клиента и сервера начинаются одинаково (`192.168.0.x`). Некоторые Wi-Fi (университетские, гостевые) **запрещают связь между устройствами**; в этом случае раздайте Wi-Fi с телефона или используйте проводное соединение |
| Нужный IP? | у Windows несколько адресов (Wi-Fi, виртуальные WSL/Hyper-V); выбирайте адрес Wi-Fi |
| «нет связи с сервером» в журнале клиента | клиент не смог подключиться (сервер не запущен / неверный IP / порт закрыт) |
| VPN | отключите на время защиты |

## Остановка

Закройте окно программы (крестик) на каждом компьютере. Правило брандмауэра удалите `ADMIN-close-port-3001.bat`.

## Сборка из исходников (по желанию)

```bash
cd airp/lab2
javac --release 11 -encoding UTF-8 -d out src/serv.java
jar cfe serv.jar serv -C out .
```

`--release 11` – чтобы `serv.jar` запускался и на Java 11 (например, на Mac). `jar cfe serv.jar serv -C out .` создаёт архив: `c` – создать, `f` – имя файла, `e` – класс точки входа (`serv`).
