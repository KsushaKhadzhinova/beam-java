7. **Отчёт**, вопросы.

## Контрольные вопросы

**1. Что такое сервлет, какие основные объекты и методы он предоставляет?** Сервлет – класс Java на стороне сервера, обрабатывающий запросы клиентов. Основные методы – `doGet` и `doPost`; объекты – `HttpServletRequest` (параметры запроса: `getParameter`) и `HttpServletResponse` (ответ клиенту: `setContentType`, `getWriter`, `getOutputStream`).

**2. Как сервлет определяется в клиентском сайте?** В форме html-документа: атрибут `action` тега `form` содержит имя сервлета (`action="MyServlet"`), а кнопка `type="submit"` отправляет данные формы. Имя сопоставляется с классом в `web.xml`.

**3. Для чего служит конфигурационный файл web.xml, поясните его структуру.** Дескриптор развёртывания: в `<servlet>` задаются имя и класс сервлета, в `<servlet-mapping>` – адрес (`url-pattern`), по которому он вызывается, в `<welcome-file-list>` – стартовая страница приложения, в `<session-config>` – настройки сессии.

**4. Как вернуть результаты, полученные в сервлете, обратно на сторону клиента?** Записать их в ответ: для текста и HTML – `PrintWriter out = response.getWriter(); out.println(...)`, для файлов (рисунок, документ) – `response.getOutputStream()` с установленным типом содержимого `setContentType("image/png")`.

## Дополнительные вопросы

- **В чём разница GET и POST?** GET – данные в адресе (видны); POST – в теле запроса.
- **Что такое Tomcat?** Контейнер сервлетов (веб-сервер для Java): принимает HTTP-запросы и передаёт сервлетам.
- **Что такое WAR?** Архив веб-приложения; кладётся в `webapps` Tomcat.
- **Почему Tomcat 9?** В нём `javax.servlet`; в Tomcat 10+ пакет называется `jakarta.servlet`.
- **Как работает обратный перевод?** Метод `translate` получает столбцы `from`/`to`; для обратного перевода они меняются местами.
- **Почему `PreparedStatement`?** Значение подставляется параметром `?` – защита от SQL-инъекций.
- **Что такое `Content-Type`?** Заголовок ответа с типом данных (`text/html`, `image/png`): по нему браузер решает, как показать содержимое.
- **Зачем буфер 4096 байт в `ImageServlet`?** Копирование файла порциями (одно из назначений буфера – выравнивание скоростей и эффективный ввод-вывод).
- **Как клиент узнаёт результат?** Читает HTML-ответ (`EntityUtils.toString`) и вырезает текст из `<h2>`.
- **Что будет, если Tomcat не запущен?** Клиент покажет «Ошибка: Connection refused».
