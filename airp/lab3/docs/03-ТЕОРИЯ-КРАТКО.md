# АИРП-3. Теория кратко

- **Сервлет** – Java-класс на сервере, обрабатывает запросы; живёт в контейнере (Tomcat 9).
- **Методы:** `doGet`, `doPost` (в лабе оба → `processRequest`). **Объекты:** `request.getParameter("имя")`, `response.getWriter().println(...)`.
- **Форма:** `<form method="Get" action="MyServlet">`, поле `name="txt"`, кнопка `type="submit"`.
- **`web.xml`:** `<servlet>` (имя, класс), `<servlet-mapping>` (адрес), `<welcome-file-list>` (стартовая страница), `<session-config>`.
- **GET** – данные в адресе; **POST** – в теле.
- **Вернуть результат:** HTML через `PrintWriter`; файл через `getOutputStream()` + `setContentType`.
- **WAR** – архив приложения, **Maven** собирает (`mvn package`), **Tomcat** запускает (`webapps/`).
- **БД:** H2 + JDBC; `SELECT eng FROM words WHERE rus = ?` и обратный `... rus ... WHERE eng = ?`.
- **Клиент:** отдельный проект, `HttpGet` + `EntityUtils.toString`, URL `http://localhost:8080/lab_servlet/MyServlet`.
- **Вариант 2:** `ImageServlet` – `image/png`, байты файла в ответ.
