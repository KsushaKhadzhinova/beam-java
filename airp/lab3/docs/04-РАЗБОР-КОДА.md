## 3. MyServlet.java: словарь

### Класс, поле и подключение базы

```java
public class MyServlet extends HttpServlet {

    private Connection connection;

    // Создание базы данных с переводами слов
    @Override
    public void init() throws ServletException {
        try {
            Class.forName("org.h2.Driver");
            connection = DriverManager.getConnection("jdbc:h2:mem:dictionary;DB_CLOSE_DELAY=-1");
            Statement st = connection.createStatement();
            st.execute("CREATE TABLE words (rus VARCHAR(50), eng VARCHAR(50))");
            st.execute("INSERT INTO words VALUES ('привет', 'hello'), ('дом', 'house'), "
                    + "('книга', 'book'), ('студент', 'student'), ('компьютер', 'computer'), "
                    + "('вода', 'water'), ('солнце', 'sun'), ('друг', 'friend'), "
                    + "('школа', 'school'), ('город', 'city')");
        } catch (Exception e) {
            throw new ServletException(e);
        }
    }

```

| Строка | Разбор |
|---|---|
| `public class MyServlet extends HttpServlet` | наш класс – **сервлет**, наследует `HttpServlet` |
| `private Connection connection;` | соединение с базой данных (одно на сервлет) |
| `@Override public void init() throws ServletException` | **инициализация**: вызывается контейнером один раз при создании сервлета |
| `Class.forName("org.h2.Driver");` | загрузить драйвер базы H2 |
| `DriverManager.getConnection("jdbc:h2:mem:dictionary;DB_CLOSE_DELAY=-1")` | подключиться к базе **в памяти** с именем `dictionary`; `DB_CLOSE_DELAY=-1` – не удалять базу, пока работает приложение |
| `Statement st = connection.createStatement();` | объект для выполнения SQL |
| `st.execute("CREATE TABLE words (rus VARCHAR(50), eng VARCHAR(50))");` | создать таблицу из двух столбцов-строк |
| `st.execute("INSERT INTO words VALUES ('привет', 'hello'), ...");` | добавить 10 пар слов |
| `catch (Exception e) { throw new ServletException(e); }` | при любой ошибке сообщить контейнеру |

### Поиск перевода

```java
private String translate(String from, String to, String word) throws Exception {
    PreparedStatement ps = connection.prepareStatement(
            "SELECT " + to + " FROM words WHERE " + from + " = ?");
    ps.setString(1, word.trim().toLowerCase());
    ResultSet rs = ps.executeQuery();
    return rs.next() ? rs.getString(1) : null;
}
```

| Строка | Разбор |
|---|---|
| `private String translate(String from, String to, String word)` | `from` – столбец, где ищем (`rus` или `eng`), `to` – столбец, откуда берём ответ, `word` – слово |
| `connection.prepareStatement("SELECT " + to + " FROM words WHERE " + from + " = ?")` | **подготовленный запрос**; `?` – место для значения |
| `ps.setString(1, word.trim().toLowerCase());` | подставить слово (без пробелов по краям, в нижнем регистре) вместо первого `?` |
| `ResultSet rs = ps.executeQuery();` | выполнить запрос; `rs` – результат (строки таблицы) |
| `return rs.next() ? rs.getString(1) : null;` | если найдена строка (`rs.next()`) – вернуть значение первого столбца, иначе `null` |

Благодаря параметру `from`/`to` **один метод** делает и перевод (`rus → eng`), и обратный перевод (`eng → rus`).

### processRequest: главный метод

```java
protected void processRequest(HttpServletRequest request, HttpServletResponse response)
        throws ServletException, IOException {
    response.setContentType("text/html;charset=UTF-8");
    PrintWriter out = response.getWriter();

    String rus_word = request.getParameter("txt"); // русское слово
    String eng_word = request.getParameter("eng"); // английское слово (обратный перевод)

    String result;
    try {
        if (rus_word != null && !rus_word.trim().isEmpty()) {
            String found = translate("rus", "eng", rus_word);
            result = found == null ? "Слово «" + rus_word + "» не найдено" : rus_word + " - " + found;
        } else if (eng_word != null && !eng_word.trim().isEmpty()) {
            String found = translate("eng", "rus", eng_word);
            result = found == null ? "Слово «" + eng_word + "» не найдено" : eng_word + " - " + found;
        } else {
            result = "Слово не введено";
        }
    } catch (Exception e) {
        throw new ServletException(e);
    }

    out.println("<html>");
    out.println("<head>");
    out.println("<title>Servlet MyServlet</title>");
    out.println("<meta http-equiv=\"Content-Type\" content=\"text/html; charset=UTF-8\">");
    out.println("</head>");
    out.println("<body bgcolor='#aaccff'>");
    out.println("<h2>" + result + "</h2><br><br>");
    out.println("<a href=\"dictionary.html\">Назад</a>");
    out.println("</body>");
    out.println("</html>");
}
```

| Строка | Разбор |
|---|---|
| `protected void processRequest(HttpServletRequest request, HttpServletResponse response) throws ServletException, IOException` | единая обработка запроса; `throws` – метод может выбросить эти исключения |
| `response.setContentType("text/html;charset=UTF-8");` | сообщить браузеру: ответ – HTML в UTF-8 |
| `PrintWriter out = response.getWriter();` | поток **для записи ответа** |
| `String rus_word = request.getParameter("txt");` | прочитать значение поля `txt` (если параметра нет, будет `null`) |
| `String eng_word = request.getParameter("eng");` | поле обратного перевода |
| `if (rus_word != null && !rus_word.trim().isEmpty())` | передано русское слово: перевести `translate("rus", "eng", ...)` |
| `else if (eng_word != null && ...)` | передано английское: `translate("eng", "rus", ...)` |
| `result = found == null ? "Слово «...» не найдено" : rus_word + " - " + found;` | формирование текста результата: **тернарный оператор** («если не найдено, сообщение, иначе пара слов») |
| `out.println("<html>");` ... `out.println("<h2>" + result + "</h2><br><br>");` | **построчно записать HTML-страницу**: заголовок `h2` с результатом и ссылка «Назад» |

### doGet и doPost

```java
    protected void doGet(HttpServletRequest request, HttpServletResponse response)
            throws ServletException, IOException {
        processRequest(request, response);
    }

    @Override
    protected void doPost(HttpServletRequest request, HttpServletResponse response)
            throws ServletException, IOException {
        processRequest(request, response);
    }
}
```

`doGet` обрабатывает запросы GET, `doPost` – POST; оба просто вызывают `processRequest`: вся логика в одном месте (так сказано в методичке).

## 4. ImageServlet.java (вариант 2)

```java
public class ImageServlet extends HttpServlet {

    protected void processRequest(HttpServletRequest request, HttpServletResponse response)
            throws ServletException, IOException {
        // Файл с рисунком находится в каталоге приложения
        InputStream in = getServletContext().getResourceAsStream("/images/picture.png");
        if (in == null) {
            response.sendError(HttpServletResponse.SC_NOT_FOUND, "Файл рисунка не найден");
            return;
        }

        // Тип содержимого: браузер сам отображает рисунок
        response.setContentType("image/png");
        OutputStream out = response.getOutputStream();
        byte[] buffer = new byte[4096];
        int length;
        while ((length = in.read(buffer)) != -1) {
            out.write(buffer, 0, length);
        }
        in.close();
        out.close();
    }

    @Override
    protected void doGet(HttpServletRequest request, HttpServletResponse response)
            throws ServletException, IOException {
        processRequest(request, response);
    }

    @Override
    protected void doPost(HttpServletRequest request, HttpServletResponse response)
            throws ServletException, IOException {
        processRequest(request, response);
    }
}
```

| Строка | Разбор |
|---|---|
| `InputStream in = getServletContext().getResourceAsStream("/images/picture.png");` | `getServletContext()` – «контекст приложения»; `getResourceAsStream` – открыть **файл из приложения** как поток; `null`, если файла нет |
| `if (in == null) { response.sendError(404, "..."); return; }` | если файла нет, отправить клиенту код 404 и выйти |
| `response.setContentType("image/png");` | **тип содержимого**: это рисунок PNG; браузер отобразит картинку, а не текст |
| `OutputStream out = response.getOutputStream();` | поток для записи **байтов** ответа (в отличие от `getWriter()` для текста) |
| `byte[] buffer = new byte[4096];` | **буфер** 4096 байт |
| `while ((length = in.read(buffer)) != -1) { out.write(buffer, 0, length); }` | читать порцию из файла и записывать в ответ, пока файл не закончится (`-1`): так копируется файл |
| `in.close(); out.close();` | закрыть потоки |

## 6. ApacheClient.java: клиент

```java
package apacheclient;

import org.apache.http.HttpResponse;
import org.apache.http.client.methods.HttpGet;
import org.apache.http.impl.client.CloseableHttpClient;
import org.apache.http.impl.client.HttpClients;
import org.apache.http.util.EntityUtils;
import javax.swing.*;
import java.awt.*;
import java.net.URLEncoder;

// Клиент словаря: вызывает сервлет по url из обычного java-приложения
public class ApacheClient {

    static String url = "http://localhost:8080/lab_servlet/MyServlet";

    // Отправка GET-запроса сервлету и выделение результата из html-ответа
    static String ask(String parameter, String word) throws Exception {
        try (CloseableHttpClient client = HttpClients.createDefault()) {
            HttpGet request = new HttpGet(url + "?" + parameter + "=" + URLEncoder.encode(word, "UTF-8"));
            HttpResponse response = client.execute(request);
            String html = EntityUtils.toString(response.getEntity(), "UTF-8");
            int start = html.indexOf("<h2>") + 4;
            int end = html.indexOf("</h2>");
            return html.substring(start, end);
        }
    }

    public static void main(String[] args) {
        JFrame frame = new JFrame("Словарь (клиент)");
        frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        frame.setLayout(new FlowLayout());

        JTextField wordField = new JTextField(15);
        JButton translateButton = new JButton("Перевести");
        JButton reverseButton = new JButton("Перевести обратно");
        JLabel resultLabel = new JLabel("Введите слово");

        translateButton.addActionListener(e -> {
            try {
                resultLabel.setText(ask("txt", wordField.getText()));
            } catch (Exception ex) {
                resultLabel.setText("Ошибка: " + ex.getMessage());
            }
        });
        reverseButton.addActionListener(e -> {
            try {
                resultLabel.setText(ask("eng", wordField.getText()));
            } catch (Exception ex) {
                resultLabel.setText("Ошибка: " + ex.getMessage());
            }
        });

        frame.add(new JLabel("Слово:"));
        frame.add(wordField);
        frame.add(translateButton);
        frame.add(reverseButton);
        frame.add(resultLabel);
        frame.setSize(520, 120);
        frame.setLocationRelativeTo(null);
        frame.setVisible(true);
    }
}
```

| Строка | Разбор |
|---|---|
| `static String url = "http://localhost:8080/lab_servlet/MyServlet";` | адрес сервлета |
| `static String ask(String parameter, String word) throws Exception` | отправить запрос с параметром `txt` (русское слово) или `eng` и вернуть результат |
| `try (CloseableHttpClient client = HttpClients.createDefault())` | создать HTTP-клиента; закрывается автоматически |
| `new HttpGet(url + "?" + parameter + "=" + URLEncoder.encode(word, "UTF-8"))` | запрос GET; слово кодируется в «%D0...» |
| `HttpResponse response = client.execute(request);` | **отправить запрос** серверу и получить ответ |
| `EntityUtils.toString(response.getEntity(), "UTF-8")` | прочитать тело ответа (HTML) как строку |
| `html.indexOf("<h2>") + 4` / `html.indexOf("</h2>")` | найти позиции начала и конца результата (4 – длина «`<h2>`»); `substring(start, end)` – вырезать текст между |
| `JFrame frame = new JFrame("Словарь (клиент)");` | окно **Swing** (современная библиотека окон вместо AWT) |
| `frame.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);` | закрытие окна завершает программу |
| `frame.setLayout(new FlowLayout());` | элементы идут подряд слева направо |
| `JTextField`, `JButton`, `JLabel` | поле ввода, кнопка, надпись |
| `translateButton.addActionListener(e -> { ... });` | обработчик нажатия в виде **лямбды**: `e -> {...}` – «получить событие `e` и выполнить блок» |
| `resultLabel.setText(ask("txt", wordField.getText()));` | при нажатии «Перевести»: спросить сервер по параметру `txt` и показать результат |
| `ask("eng", ...)` | для «Перевести обратно» |
| `catch (Exception ex) { resultLabel.setText("Ошибка: " + ex.getMessage()); }` | при ошибке (например, Tomcat не запущен) показать сообщение |
| `frame.setVisible(true);` | показать окно |
