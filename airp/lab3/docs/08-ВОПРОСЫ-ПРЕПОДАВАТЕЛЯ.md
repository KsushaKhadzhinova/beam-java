# ЛР3. Вопросы преподавателя и ответы

Четыре «Контрольных вопроса» из методички и вопросы по материалам лекций (Tomcat, JSP, сервлеты, WAR).

---

## Контрольные вопросы из методички

### 1. Что такое сервлет, какие основные объекты и методы он предоставляет?
**Сервлет** — Java-класс на стороне сервера (наследник `HttpServlet`), который выполняется внутри **сервлет-контейнера** (Tomcat, GlassFish) и отвечает на HTTP-запросы.

| Что | Назначение |
|---|---|
| `HttpServletRequest request` | запрос: `getParameter("txt")`, `getMethod()`, `getHeader()`, `getRequestURI()` |
| `HttpServletResponse response` | ответ: `setContentType`, `getWriter()`, `getOutputStream()`, `sendError` |
| `doGet`, `doPost` | обработка GET/POST (в лабе оба вызывают `processRequest`) |
| `init()` / `destroy()` | вызываются при загрузке и выгрузке сервлета |
| `getServletContext()` | доступ к ресурсам приложения (файл рисунка) |

**Жизненный цикл:** контейнер создаёт один экземпляр → `init()` один раз → на каждый запрос `service()` → `doGet/doPost` в отдельном потоке → `destroy()` при остановке.

### 2. Как сервлет определяется в клиентском сайте?
В html-форме: `<form method="Get" action="MyServlet">` — атрибут **`action`** содержит URL сервлета (относительно приложения). Кнопка `type="submit"` отправляет поля формы, `name="txt"` определяет имя параметра, которое читается как `request.getParameter("txt")`. Метод `method="Get"` → вызовется `doGet`.

### 3. Для чего служит `web.xml`, структура?
Дескриптор развёртывания приложения (`WEB-INF/web.xml`):
- `<servlet>` — **имя** сервлета и его **класс** (`<servlet-name>`, `<servlet-class>`);
- `<servlet-mapping>` — связывает имя с **URL** (`<url-pattern>/MyServlet</url-pattern>`);
- `<welcome-file-list>` — стартовая страница (`dictionary.html`);
- `<session-config><session-timeout>30</session-timeout>` — время жизни сессии: **30 минут** бездействия (на слайде лекции написано «30 с», но в `web.xml` единица — минуты).

### 4. Как вернуть результаты из сервлета на сторону клиента?
- Текст/html: `response.setContentType("text/html;charset=UTF-8"); PrintWriter out = response.getWriter(); out.println("<html>…")`.
- Бинарные данные (рисунок, музыка, документ): `setContentType("image/png")` и запись байтов в `response.getOutputStream()` — так работает `ImageServlet`.
- Либо перенаправление: `response.sendRedirect(url)`.

## Вопросы по лекциям (из чата)

### Что такое Tomcat?
Веб-сервер и **сервлет-контейнер** (Apache Tomcat 9). Принимает HTTP-запросы на порту **8080**, находит нужное приложение в папке `webapps` и вызывает его сервлет. Управление: `catalina run` (запуск), `shutdown`. Пользователи для менеджера — в `conf/tomcat-users.xml`.

### Что такое WAR?
Архив веб-приложения (Web ARchive): `jar -cvf mein2.war jsp1.jsp` (команда с лекции). Положенный в `webapps`, он автоматически распаковывается и разворачивается. В лабе WAR собирает Maven: `lab_servlet.war`.

### Что такое JSP и чем отличается от сервлета?
JSP — html-страница со вставками Java (`<%= getDate() %>`, `<%! … %>`, `<% … %>`). При первом обращении Tomcat **превращает JSP в сервлет** и компилирует. Сервлет — «Java с html внутри», JSP — «html с Java внутри».

### GET и POST
- **GET** — параметры в URL (`?txt=дом`), видны, длина ограничена, можно закладку; для чтения.
- **POST** — параметры в теле запроса, не видны в адресной строке; для отправки/изменения данных.
(В методичке сказано «данные разбиваются на несколько пакетов» — упрощённое объяснение.)

### Что такое `HttpURLConnection`?
Класс из `java.net` для HTTP-запросов из обычной Java-программы: `url.openConnection()`, `setRequestMethod("GET")`, `getResponseCode()` (200 = OK), `getInputStream()`. Наш клиент `ApacheClient` делает то же через библиотеку Apache HttpClient.

### Зачем клиент и сервер в разных проектах?
Чтобы показать, что сервлет — это **сервис по URL**: к нему можно обратиться из браузера, из Java-приложения (`ApacheClient`) или из любой другой программы.

### Почему база данных H2?
Встраиваемая БД, не нужна установка: `jdbc:h2:mem:dictionary` создаёт таблицу `words(rus, eng)` в памяти при `init()`. Драйвер лежит в WAR (`WEB-INF/lib/h2-2.2.224.jar`).

## Вероятные вопросы по коду

| Вопрос | Ответ |
|---|---|
| Зачем `PreparedStatement` и `?` | Защита от SQL-инъекций, значение подставляется безопасно |
| Откуда сервлет берёт рисунок | `getServletContext().getResourceAsStream("/images/picture.png")` — из папки `webapp` |
| Зачем `setContentType("image/png")` | Браузер должен знать, что в ответе картинка, а не текст |
| Что вернёт сервлет для неизвестного слова | Страницу «Слово … не найдено» |
| Почему URL клиента `…/lab_servlet/MyServlet` | `lab_servlet` — имя WAR (контекст), `MyServlet` — `url-pattern` |
| Что если Tomcat не запущен | `ApacheClient` покажет «Ошибка: Connection refused» |
| В чём разница `javax.servlet` и `jakarta.servlet` | `javax` — Tomcat ≤ 9, `jakarta` — Tomcat 10+/GlassFish 7 (на лекции использовался `jakarta`, у нас Tomcat 9 → `javax`) |
