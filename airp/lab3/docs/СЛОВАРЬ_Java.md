# Словарь символов и слов Java

Java и C# очень похожи. Если вы знаете словарь C#, здесь добавлено то, что отличается.

## Знаки (то же, что в C#, плюс особенности)

| Знак | Что значит |
|---|---|
| `;` | конец команды |
| `{ }` | блок кода |
| `( )` | вызов метода, параметры, условия |
| `[ ]` | массив (`String[] args`) |
| `< >` | обобщения: `ArrayList<String>` – список строк |
| `=` / `==` | присваивание / сравнение (для строк используют `.equals(...)`, а не `==`) |
| `+` для строк | склеивание: `"Account:" + amountstring` |
| `->` | лямбда-выражение: `e -> System.out.println(e)` |
| `::` | ссылка на метод |
| `@Override` | аннотация: «этот метод переопределяет метод родителя» |
| `//` и `/* */` | комментарии |
| `\n` | перенос строки внутри строки |
| `\|` в `split("\\|")` | в регулярных выражениях `\|` – символ «вертикальная черта» |

## Слова

| Слово | Что значит |
|---|---|
| `package` | «папка» класса, например `package web_res_lab;` |
| `import` | подключить класс из другого пакета (аналог `using` в C#) |
| `class` | класс |
| `extends` | наследование: `class Account extends Thread` – класс **расширяет** `Thread` (это поток) |
| `implements` | реализация интерфейса: `implements ActionListener` |
| `interface` | интерфейс |
| `public` / `private` / `protected` / (ничего) | доступ: всем / внутри класса / наследникам и пакету / только пакету |
| `static` | принадлежит классу (общий для всех объектов) |
| `final` | константа / нельзя переопределить |
| `void` | метод ничего не возвращает |
| `int`, `double`, `boolean`, `String`, `Object` | тип «целое», «дробное», «да/нет», «строка», «любой объект» |
| `new` | создать объект |
| `this` / `super` | текущий объект / родительский класс |
| `try` / `catch` / `finally` | обработка исключений |
| `try (ресурс) { }` | **try-with-resources**: ресурс закроется автоматически |
| `throws` | метод может выбросить исключение |
| `return` | вернуть значение |
| `synchronized` | блок/метод, который одновременно выполняет только один поток |
| `Thread` | поток; `start()` запускает, `run()` – что поток делает |

## Основные классы из лабораторных

| Класс | Зачем |
|---|---|
| `Frame`, `Button`, `TextArea`, `TextField`, `Label` | окно и элементы управления (библиотека AWT) |
| `ActionListener` | «слушатель» нажатия кнопки; метод `actionPerformed` вызывается при нажатии |
| `File` | файл или папка (`new File("medicines.txt")`) |
| `URL`, `URLConnection` | адрес ресурса и соединение с ним |
| `InputStream` / `InputStreamReader` / `BufferedReader` | чтение: байты → символы → строки с буфером |
| `PrintStream` / `PrintWriter` | запись текста (`println`) |
| `Socket`, `ServerSocket` | клиентский и серверный сокеты |
| `Thread` | поток |
| `HttpServlet`, `HttpServletRequest`, `HttpServletResponse` | сервлет, запрос, ответ |
| `Desktop` | запуск программ по умолчанию, например браузера |
| `Math.random()` | случайное число от 0 до 1 |

## Как читать строку кода (пример)

```java
s = new Socket("127.0.0.1", 3001);
```

1. `s` – ранее объявленная переменная типа `Socket`.
2. `=` – положить в неё…
3. `new Socket(...)` – создать клиентский сокет…
4. `"127.0.0.1"` – адрес компьютера (свой компьютер);
5. `3001` – номер порта (адрес приложения внутри компьютера);
6. `;` – конец.
